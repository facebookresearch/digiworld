Transit App - High-Level Feature Overview
What is the Transit App?
The Transit App is a mobile application that helps users plan, navigate, and track their public transportation journeys. It provides real-time information about buses, trains, subways, and other transit options to make getting around the city easier.
Core Features
1. Plan Your Trip (Plan Tab)
Users can search for the best route from one location to another.
What you can do:
Enter starting point and destination
Choose a departure or arrival time
Filter by transportation type (bus, subway, train, streetcar)
See recent searches for quick access
View multiple route options with different tradeoffs
Key interactions:
Search for trips with one tap
Swap starting point and destination instantly
Use current location as starting point
Get directions from your favorites
Reference screen: [Reference screen for Plan Tab]
Search Results Screen
When you search for a trip, you'll see multiple options.
You can:
Sort by fastest route, fewest transfers, earliest arrival
Compare fare prices and travel duration
See walking distances and transfer counts
Filter results to match your preferences
Reference Screen: [Reference screen for Search Results]
Trip Details Screen
Get complete step-by-step directions for your chosen route.
You see:
Each step of your journey (walking, waiting, riding)
Which line/bus you need to board
Pickup and dropoff stops
Total fare breakdown
Option to save the route
2. Find Nearby Transit (Nearby Tab)
See what transit options are closest to you right now.
What you can do:
View transit stops near your current location [Assuming current location will be home location] mock just near by one of the stop of 1 to 10
See next 3 arrivals at each stop
Check distance to each stop
Filter by transport type
See real-time updates
Key interactions:
Tap a stop to see full details
Get directions to a specific stop
Refresh to get latest arrival times
Toggle between map and list view
Stop Details Screen
Complete information about a specific transit stop.
You can see:
Real-time arrivals for all lines at this stop
Facilities available (shelter, seating, accessibility)
Nearby amenities and landmarks
Service alerts affecting this stop
Map location
Get directions to this stop
3. Save Your Routes (Routes Tab)
Keep track of routes you use frequently.
What you can do:
Save your favorite commutes
Mark routes as favorites
See which routes you use most
Quick-start navigation from saved routes
Key interactions:
One-tap navigation from saved routes
Edit or delete saved routes
Schedule departure reminders
4. Manage Your Profile (Profile Tab)
Customize your app settings and preferences.
What you can do:
Set home and work addresses
Choose preferred transit modes (bus, subway, train, streetcar)
Configure notification preferences
Change language settings
Manage account and privacy settings
Line Details Screen
Information about a specific transit line.
Includes:
Route map showing all stops [bus, subway, train]
Service hours and frequency
Current service status
Full timetable and schedule
Any active alerts or disruptions
Alternative service information
Service Alerts Screen
Stay informed about transit disruptions and delays.
Features:
View all active service alerts
See planned maintenance
Filter by severity level
Get alternative route suggestions
Share alert information with others
How It Works: User Journey
Example: Morning Commute
Open App → Lands on Plan tab
Search → Enter home and work addresses, set departure time
Choose Route → Pick fastest option from results
View Details → See step-by-step directions
Save Route → Option to save for future use
Example: Exploring Nearby Options
Open App → Go to Nearby tab
See Stops → View closest transit stops on map
Check Arrivals → See next buses/trains at each stop
Tap Stop → View full stop details and schedule
Navigate → Get directions to stop or plan trip from there
Data Management
Saves recent searches locally
Stores saved routes for quick access
Keeps trip history for statistics
Caches transit network data
Updates service alerts continuously
