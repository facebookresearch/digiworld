# Email App Feature Scope

This document outlines the features that have been implemented in the Andojo Email App. Each feature is grouped by functional area for clarity.

## 1. User Management
- **User Registration & Login:** Secure authentication with email and password.
- **Profile Management:** Users can update their profile details, including name, avatar, and contact information.
- **Password Management:** Support for password change and reset flows.
- **Role Management:** User roles (user/admin) with access control.

## 2. Email Management
- **Compose Email:** Create and send new emails with support for subject, body, attachments, CC, and BCC.
- **Inbox, Sent, Drafts, Archive, Trash, and All Mails Folders:** Organize emails into standard folders. (Custom/user-defined folders are not supported.)
- **Read/Unread Status:** Mark emails as read or unread; unread count is tracked.
- **Drafts:** Save and edit draft emails before sending.
- **Delete & Archive:** Move emails to trash or archive folders.
- **Search & Filter:** Search emails by sender, subject, or content; filter by folder or status.
- **Attachments:** Attach and download files with emails.

## 3. Dummy Settings Menu
- **Theme Selection:** Choose between light, dark, or system theme.
- **Language Preferences:** Set preferred language for the app UI.
- **Notification Settings:** Enable or disable push/email notifications.
- **Emails Per Page:** Configure how many emails are shown per page.

## 5. Miscellaneous
- **CC/BCC Support:** Add carbon copy and blind carbon copy recipients.
- **Preview Pane:** Show a short preview of email content in the list view.
- **Timestamps:** All emails and actions are timestamped for tracking.
