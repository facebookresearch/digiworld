# Andojo Email App

## Overview
This is the email application for the Andojo platform, built with React Native and Expo. It leverages Drizzle ORM and SQLite for local data management, and is designed for robust, user-friendly email communication on mobile devices.

## Features
- User authentication and account management
- Compose, send, receive, and organize emails
- Inbox, Sent, Drafts, and custom folders
- Email threading and conversation view
- Mark emails as read/unread
- Email search and filtering
- Attachments support
- User and email-specific settings (themes, notifications, signatures, etc.)
- Support for labels, priority, and folders
- Vacation auto-reply and read receipts
- Mobile-optimized UI/UX
