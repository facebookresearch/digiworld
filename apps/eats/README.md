# Andojo Eats App

## Overview
This is the food delivery application for the Andojo platform, built with React Native and Expo. It uses Drizzle ORM and SQLite for local data management, and is designed to provide a robust, user-friendly food ordering and delivery experience on mobile devices.

## Features
- User authentication and profile management (phone number + OTP)
- Browse restaurants, categories, and menu items
- Add items to cart and manage cart contents
- Select or add delivery addresses
- Choose (mocked) payment methods
- Place orders and track order status
- Offline map-based order tracking
- Search for restaurants, menu items, and categories
- All data stored locally (no backend required for MVP)
- Mobile-optimized UI/UX
