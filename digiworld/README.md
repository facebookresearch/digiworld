# DigiWorld — Python Package

The `digiworld` Python package: scenarios, state data, and CLI. For the overview,
installation, and full documentation, see the [root README](../README.md).

## Quick Setup

```bash
pip install -r requirements.txt
digiworld --version
digiworld list
```

## Package Contents

This directory contains the `digiworld` Python package:

- `digiworld/` -- Python package (scenarios, state data, CLI)
- `demos/` -- Demo applications (scenario explorer, agent environment)
- `utils/` -- Utility scripts (cleanup, summary, task export)
- `qa_validation/` -- Human-in-the-loop validation interface
- `pyproject.toml` -- Package configuration
- `requirements.txt` -- Installation dependencies
